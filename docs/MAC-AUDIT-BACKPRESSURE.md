# MAC 审计背压策略

更新时间：2026-11-19。

状态：**256 是 fail-closed 审计队列策略，不是可静默扩容的业务容量。**

## 语义

`MacEngine::authorize` 在审计队列已满时：

1. 不执行目标授权效果；
2. 返回 `MacDenial::AuditFull`；
3. 增加 `overflow_attempts` 诊断计数。

这条路径优先保证“未审计的成功授权不可能发生”，而不是为了继续授权而丢弃审计
记录。collector 必须先 drain；生产部署若需要更高峰值，应依据实际审计吞吐和内存
预算创建不同的显式策略，而不是在运行时静默覆盖记录。

## 验证

现有测试将队列填满后验证下一次授权失败、pending 保持容量、overflow 计数递增。
该策略与 Issue #39 的统一授权/审计基础设施绑定。

## 尚未完成

- 本结论不把其它固定策略或运行期容量自动视为已完成。

## 一、分层

自下而上，只允许向下依赖：

| 层 | 位置 | 职责 |
|---|---|---|
| 指令集接缝 | `kernel/src/arch/` | `Platform` 契约（trait）：控制台、描述符表/异常、中断控制器与定时器、中断开关、上下文切换、页映射、地址空间、进入用户态。每个指令集一个实现目录，缺项即编译失败 |
| 纯机制库 | `kernel-core/` | 与硬件、引导方式无关的机制，宿主可测：对象与带世代计数的句柄表、权限位、等待集合、异步 ring、页帧位图分配、页映射契约、堆算法、模块装配、陷入分发、结构化追踪、自旋锁 |
| 内核基础设施 | `kernel/src/{console,irq,clock,boot}.rs` | UTF-8 控制台（整行原子输出）、逻辑中断线与延迟处理、时钟、与引导协议无关的交接信息 |
| 调度 | `kernel/src/sched/` | 机制（任务表、状态迁移、切换计划）与策略（`SchedPolicy`，默认轮转）分离；切换事件经观察者通知 |
| 内存 | `kernel/src/mm/` | 全局页帧服务、内核映射服务、内核堆（`#[global_allocator]`）、独立地址空间 `VmSpace` |
| 主流程 | `kernel/src/kmain.rs` | 架构无关的启动与里程碑演练序列 |
| 引导适配 | `kernel/src/main.rs` | 把 `bootloader` 的 `BootInfo` 转成中立的 `BootSpec`；换引导方式只改这里 |

**Core**（`arch/` 与 `main.rs` 之外的全部代码）不得出现 ISA 专有代码；验收脚本用 grep 机械检查，并带负向用例。

## 二、关键机制

### 调度
- 每个任务一块静态、16 字节对齐的内核栈；`switch_context` 只保存 callee-saved 寄存器与栈指针
- 抢占：定时器中断**先 EOI 再进入调度器**，时间片由策略给出；所有切换在关中断临界区内完成
- 任务携带地址空间与内核栈顶：切换任务时同时切换地址空间、更新「从用户态进入内核时的栈」

### 内存
- 页帧：位图分配器，帧 0 永不分配，保留区优先，重复释放 / 释放保留内存 / 未对齐均返回规范错误
- 映射：Core 只定义中立权限位（写 / 执行 / 用户 / 全局）与 `PageMapper` 契约；x86_64 用 4 级页表实现
- 堆：按地址排序空闲链表 + 首次适配 + 释放合并；固定虚拟区间上按需映射增长
- 地址空间：每个空间有私有窗口，窗口外共享内核映射；销毁时回收全部私有页表帧

### 用户态
- 经 `iretq` 进入特权级 3；用户态的缺页、保护错误、无效指令**只终止该任务**，内核继续调度
- 事件以结构化标记输出：`system.task.faulted`

### 系统调用与用户程序
- 陷入指令在 `arch/`；Core 按 `system.<领域>.<对象>.<动作>` 名字分发，数字 ID 由人写在 `abi/system-ids.txt`，
  构建期校验命名并检查已发布的 ID 未被删除、改号或改名（违反即构建失败）
- 每个任务有可用调用集合（统一权限检查）；用户指针一律先校验再经物理映射复制
- 进程拥有地址空间、句柄表与帧；最后一个线程停止即退出并关闭句柄表；对象在全部强引用释放后由清理过程销毁
- 句柄权限只可降低；跨进程转移在同一把锁内先检查后提交

### 异步 I/O（`kernel-core::io`）
- 只有「提交 → 完成」：提交时即预留完成槽位，完成永不丢失
- 取消只能把请求从提交队列摘除一次，每个请求恰好一条终态完成，不会重复完成

## 三、构建与验收

```bash
bash scripts/accept.sh
```

验收序列（一次真实启动覆盖全部已完成里程碑）：

1. `cargo test -p kernel-core`（宿主单元测试）与 `kernel-core` 的裸机目标编译
2. 构建 `jasper-kernel` 与 BIOS 可引导镜像（`xtask`）
3. QEMU 真实启动，`isa-debug-exit` 退出码 33 表示成功
4. 按串口标记逐里程碑判定：`[JSR-BOOT]` `[JSR-TICK]` `[JSR-SCHED]` `[JSR-OBJ]` `[JSR-FRAME]` `[JSR-MAP]` `[JSR-HEAP]` `[JSR-AS]` `[JSR-USER]` 等

默认把编译与 QEMU 限制在 4 个核（`taskset -c 0-3`），可用环境变量 `JASPER_CORES` 覆盖。

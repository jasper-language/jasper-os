# 规则（issue #8）：
#   * 采用 Major.Minor.Patch；Major 是世代，Minor 是世代内的兼容增量，Patch 是不改变契约的修订。
#   * 同一 Major：新的 Minor 必须向后兼容此前所有稳定 Minor；Minor 不得回退。
#   * 新 Major：允许完全不兼容；必须随新内核发布新的 ABI 快照（锁文件头随之换代）。
#   * 内核版本与本文件的版本独立编号；内核内部优化不得顺带升级 Major。
#   * 构建链把本文件同时用于内核声明与用户程序 ABI 章；两者由构建期一致性检查锁死。
#
# 文件格式：每行 `键 = 值`，只允许 major / minor / patch 三个键，值必须是 0..=65535。

minor = 7
patch = 0

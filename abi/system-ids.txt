# 规则：
#   * 数字 ID 由人显式分配；只能追加，已发布的 ID 永不删除、改号、改名、改种类
#     （已发布 = 出现在 system-ids.lock 中；构建期机械检查，违反即构建失败）
#   * 操作（op）ID 从 1 起；错误码（error）ID 从 4097 起，系统调用以 -(ID) 返回错误
#   * 名字遵守 system.<领域>.<对象>.<动作> 命名约定（构建期 lint）
#   * 每个登记的操作都必须在内核里有真实实现，否则内核启动自检失败
#
# 列（制表符分隔）：ID  种类  名字  版本  副作用  中文显示名  英文显示名
#   * 中文显示名与英文显示名都必填；英文显示名是第 6 个制表符之后的整行剩余部分（首尾无空白）
#   * 英文显示名只含可打印 ASCII（0x20–0x7E），内部可含单个空格，不含连续空格与 #
